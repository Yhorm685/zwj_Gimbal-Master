# 姿态、控制与通信

## 一个控制周期

TIM2 以 100 Hz 触发 FreeRTOS 控制任务。MPU6050 沿用框架的 DLPF=3、分频值 7，按 125 Hz 更新数据寄存器。每次控制触发读取最新一组六轴值，按 g 与 °/s 传给控制器。控制器先检查控制间隔和传感器数据，再更新姿态、保护状态及舵机位置指令。TIM3 输出 50 Hz PWM，串口任务异步发送 20 Hz 姿态遥测。

上电进入 `CAL`。静止时连续采集 200 个样本，检查加速度模长、角速度大小及方差，估计陀螺零偏，用平均重力向量初始化 roll、pitch，并将 yaw 定为零。按 100 Hz 计算，连续静止约需 2 s。转动或振动会延长等待。校准过程中保持平台静止，绕竖直轴极慢匀速转动可能被六轴传感器误判为静止。

后续使用带比例重力校正的 Mahony 六轴姿态更新。陀螺积分更新单位四元数，加速度模接近 1 g 时，用实测重力与预测重力的叉积校正角速度。GUI 中的 Kp 调整此项，取值 0 至 10，默认 1.5。Kp 为 0 时只按校准后的陀螺积分。有显著平动加速度时暂停重力校正。在线调整后用 `PARAM` 回包核对实际值。

## 双轴执行

姿态外环把每轴目标误差换算为期望角速度，内环根据期望与实测角速度之差修正输出速度，积分后送到 SG90 内置的位置伺服。俯仰与偏航角速度由陀螺分量按当前姿态换算。两个环共用一次 IMU 采样。

初始参数为每轴目标 ±35°、舵机逻辑输出 45° 至 135°、中位 90°、指令斜率上限 70°/s。方向及关节边界集中在 `Module/gimbal.cpp` 的轴标定常量。使用前须测量安全行程并按实际装配调整。首次解锁前将机构置于标记中位，解锁时目标姿态取当前姿态，随后才接受目标变化。SG90 缺少可读关节编码器，软件不能从任意上电轴位估计舵机的真实位置。

| 状态 | 进入途径 | 操作 |
| --- | --- | --- |
| CAL | 上电、人工 RESET | 输出关闭，等待静止校准 |
| READY | 校准完成，或 ACTIVE 时 STOP | 新鲜蓝牙心跳和人工 ARM 后进入 ACTIVE |
| ACTIVE | 蓝牙 ARM 成功 | 接受目标、限幅限速，持续检查传感器、定时和心跳 |
| FAULT | 运行故障或失联 | 输出关闭。重新连接仍保持锁定；排除原因后 RESET，重新校准、发心跳、人工 ARM |

心跳超时为 500 ms。控制器还检查角速度饱和、无效计算、异常控制间隔和倾角。在 ACTIVE 时，任一轴误差持续超过 5° 达 1.25 s 会关断。命令持续向同一轴的软件限位外推 1.25 s 也会触发关断。阈值须随实际机构验证。软件 STOP、再次 ARM 和软件 RESET 会保留最近的舵机命令。断电后如果负载移动了轴，下一次解锁前需人工复核机械基准。

## 串口约定

ASCII 单行命令，以 LF 或 CRLF 结尾，一个端口单独维护一行。十进制角度单位 °，无单位的 Kp 为滤波权重。单条命令正文最多 47 字节。收到非法行、未知命令或越界值会返回错误；串口缓冲溢出后应丢弃到下一行边界。

| 命令 | 端口 | 含义 |
| --- | --- | --- |
| `PING` | 蓝牙 | 刷新心跳，建议每 100 ms 发送 |
| `ARM` | 蓝牙 | 人工解锁 |
| `TARGET 5 -3` | 蓝牙 | 设置 yaw、pitch 相对目标（°） |
| `GAIN 1.5` | 有线 | 设置加速度校正权重，回读生效值 |
| `GET` | 两端 | 查询权重 |
| `STOP` | 两端 | 立即请求解除使能 |
| `RESET` | 两端 | 从停止或故障状态重新校准 |

应答为 `OK <命令>` 或 `ERR <命令>`。参数回读另发一行 `PARAM <值>`。USB 遥测字段顺序为：

```text
T,ms,roll,pitch,yaw,target_yaw,target_pitch,state,gain,missed,exec_us
```

`ms` 是板上毫秒时基，`missed` 是累计漏周期数，`exec_us` 是控制执行时间（µs）。按到达顺序记录原始数据。一个蓝牙串口会话应由同一个操作者控制；独立的 USB 连接可以同时用于曲线、记录和调参。
